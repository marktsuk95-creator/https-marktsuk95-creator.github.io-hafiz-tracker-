# Hafiz Tracker — запуск в Telegram

Всё приложение — один файл `index.html`. Сервер и база не нужны: данные каждого пользователя
хранятся в Telegram CloudStorage (привязаны к его аккаунту и синхронизируются между устройствами).

## 1. Выложить в интернет (GitHub Pages, бесплатно)

1. Зарегистрируйтесь на github.com → **New repository** → имя `hafiz-tracker`, Public → Create.
2. **Add file → Upload files** → перетащите `index.html` → Commit.
3. **Settings → Pages** → Source: *Deploy from a branch*, Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты появится адрес вида `https://ВАШ_НИК.github.io/hafiz-tracker/` — откройте его и проверьте.

## 2. Создать бота и подключить Mini App

1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя (например *Hafiz Tracker*)
   и username (например `hafiz_tracker_bot`).
2. Кнопка в меню бота: `/mybots` → ваш бот → **Bot Settings → Menu Button → Configure menu button**
   → отправьте ссылку из шага 1 → название кнопки: `Открыть трекер`.
3. (Желательно) Прямая ссылка на приложение: `/newapp` → выберите бота → название, описание,
   картинка 640×360 → ссылка из шага 1 → короткое имя `app`.
   Получится ссылка `https://t.me/hafiz_tracker_bot/app` — её удобно давать в описании рилса.

Готово: открываете бота → кнопка «Открыть трекер».

## Как обновлять

Изменили `index.html` → снова загрузили его в репозиторий (Upload files с заменой).
Через минуту у всех пользователей откроется новая версия. Прогресс при этом не теряется.

## Что внутри

- **Обучение** — 5 экранов при первом запуске (что такое сабак, сабки, манзиль); снова открывается кнопкой «?» в шапке.
- **Сегодня** — кольцо прогресса (из 604 страниц), серия дней, неделя, план: сабак / сабки / манзиль.
- **Прогресс** — карта 30 джузов, отметка страниц, темп в неделю, прогноз «хафиз через N месяцев»,
  выбор порядка заучивания (с 30-го джуза или с Аль-Фатихи).
- **Намазы** — 5 отметок в день и таблица за неделю.

Разметка страниц — Мединский мусхаф (604 стр.). Список сур и страниц стоит один раз показать устазу.
